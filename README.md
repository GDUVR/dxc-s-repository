# Recruitment Test

新生招募测试题，共三道题目，请按顺序完成。

## 目录结构

- [`01_python_setup/`](01_python_setup/README.md) 第一题：安装 Python 3.10 环境。
- [`02_image_recognition/`](02_image_recognition/README.md) 第二题：使用 `generate.exe` 生成图片，配置并修改 `run.py` 完成图片识别。
- [`03_cmake_build/`](03_cmake_build/README.md) 第三题：配置 CMake / MinGW 工具链，编译并运行 C++ 题目工程。

## 说明

每道题目文件夹下都有独立的 `README.md`，包含具体的操作步骤和填空要求。请依次阅读并完成，将各题答案填写到指定的收集表中。
